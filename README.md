# DASP-SR
Official repository for the paper:
**Degradation-Aware and Structure-Preserving Diffusion for Real-World Image Super-Resolution**
## Status
The full code is not publicly available at this time.
We are currently organizing the training code, inference code, pretrained models, and related documentation for public release. They will be made available after the paper publication process is completed.
## Overview
DASP-SR is a diffusion-based framework for real-world image super-resolution.  
It improves restoration quality with degradation-aware conditioning and structure-preserving noise design.
